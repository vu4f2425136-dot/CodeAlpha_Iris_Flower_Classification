# Iris Flower Classification

## Project Overview

This project uses machine learning to classify Iris flowers into three species:
- Setosa
- Versicolor
- Virginica

## Objective

The objective is to build a machine learning classification model that predicts the species of an Iris flower based on its measurements.

## Dataset

The Iris dataset contains measurements of Iris flowers, including:
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

## Technologies Used

- Python
- Pandas
- Matplotlib
- Scikit-learn
- Google Colab

## Methodology

1. Loaded the Iris dataset.
2. Explored the dataset and checked for missing values.
3. Visualized the flower measurements.
4. Divided the data into training and testing sets.
5. Trained a Logistic Regression classification model.
6. Made predictions on the test data.
7. Evaluated the model using accuracy, confusion matrix, precision, recall, and F1-score.
8. Tested the model with a new flower sample.

## Model

Logistic Regression was used as the classification algorithm.

## Result

The model was evaluated using the test dataset. The accuracy and classification performance are shown in the project notebook.

## Conclusion

The project demonstrates the basic workflow of a machine learning classification problem, including data preparation, visualization, model training, prediction, and evaluation.
